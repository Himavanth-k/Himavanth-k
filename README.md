# Hi, I'm Himavanth K 👋

### Forward Deployed Engineer · Bangalore, India 🇮🇳

I build and ship production software that sits close to the customer — and close to the data behind it. My work spans a Flutter commerce app, the Shopify platform underneath it, and the internal tools that keep both honest.

---

## 💼 What I Work On

**Forward Deployed Engineer @ [Organic Mandya](https://organicmandya.com)** — a D2C organic grocery brand.

🔹 **Mobile** — Flutter app for Android and iOS: product catalogue and category filtering, search, checkout, subscriptions and deep linking.

🔹 **Commerce platform** — Shopify Storefront and Admin APIs, GraphQL, catalogue data quality, smart collections and product taxonomy. A lot of the interesting work lives in the gap between what the app expects and what the store actually holds.

🔹 **Internal tools** — Next.js dashboards on Supabase for catalogue and order insight.

🔹 **Release engineering** — GitHub Actions pipelines, contract tests that run against live APIs, and Android/iOS release configuration including App Links and Universal Links.

I like problems where the bug isn't in the code: a dangling collection id that renders as an empty shelf, a tag that silently spread across most of a catalogue, a config that claims to be deployed and isn't.
